# Store OS

Inventory Management System for Floor Inventory, Store, Issue Vouchers, IR/Move Orders, BOM and Slow Moving inventory.

## Features

- PDF and Excel import
- Manual add and clear per section
- Slow Moving cost lookup by Item Code
- Inventory and Store cost calculation
- Issue Voucher inventory/store quantity adjustment
- BOM parent-child search and cost total
- Dashboard cost summary
- Glassmorphism animated UI
